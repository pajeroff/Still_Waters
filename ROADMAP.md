### Управление
- [x] `CharacterBody2D` двигается через `move_and_slide()` в floating-режиме.
- [x] WASD и стрелки, левый аналоговый стик, бег на Shift / нажатие стика.
- [x] Ввод переводится в изометрическое направление: `Vector2(input.x - input.y, (input.x + input.y) * 0.5)`.
- [x] Направление выбирается по восьми экранным секторам; диагональная скорость нормализована.
- [x] Плавные ускорение и торможение; сила отклонения стика сохраняет аналоговую скорость.
- [x] В `InputMap` во время старта регистрируются `move_up/down/left/right`, `run`, `interact`, `cast`, `reel`, `inventory`, `pause`, `map`, `skill_tree`, `achievements`.
- [x] Dead zone направлений стика — 0.2.
- [ ] Перенести настройки InputMap из runtime-инициализации в редактор проекта, если понадобится настраивать раскладку без кода.
