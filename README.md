# Still Waters

Небольшой прототип на **Godot 4.7**: тихая лесная поляна, тропинка к озеру и управляемый персонаж. Арт персонажа и природные объекты извлечены из `pers.png` и `texture.png`, которые уже лежат в репозитории.

## Запуск

Откройте `project.godot` в Godot 4.7 и нажмите **F6/F5** (для запуска основной сцены — F5).

## Управление

- **WASD** или **стрелки** — движение
- **Shift** — быстрый шаг

Пока это основа мира: свободное перемещение, камера за персонажем, озеро, лесная кромка и небольшие детали окружения. Игровых заданий и боевых механик пока нет.
