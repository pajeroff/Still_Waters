# «Тихий Омут» — Godot 4.7

Изометрический movement-first прототип. При запуске открывается `World.tscn`: авторская сцена Старого пруда, восьминаправленный рыбак, ходьба/бег, физические препятствия, Y-sort и сглаживаемая камера.

## Запуск

Откройте проект в Godot 4.7 и запустите проект. Стартовая сцена — `World.tscn`. Ранний прототип рыбалки сохранён в `Main.tscn`, но сейчас не является стартовой сценой.

## Управление

- **WASD / стрелки** — движение по изометрическому миру.
- **Левый стик** — плавное движение; dead zone 0.2.
- **Shift / нажатие левого стика** — бег.
- **E / A на геймпаде** — взаимодействие рядом с точкой.
- **Колесо мыши / = и -** — масштаб камеры 1× / 2×.

## Графика

- `assets/world_backdrop.png` — сгенерированная пиксельная карта берега, пруда, дорожки и мостков.
- `assets/angler_sheet.png` — лист кадров рыбака: 8 направлений, idle и ходьба.
- `assets/{oak,birch,shrub,bush,reeds,flowers,boulder,stump,sign,lantern,lily_pads,fern}.png` — сгенерированные игровые спрайты.
- Оригинальные атласы сохранены в `assets/source/`. Производные файлы можно пересобрать: `python tools/slice_ai_assets.py` (требуется Pillow).
